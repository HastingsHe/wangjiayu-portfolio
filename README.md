# Wang Jiayu — Artist Portfolio

A bilingual portfolio of painting, installation and moving image.

## GitHub Pages

Publish from the `main` branch, `/ (root)` in Settings → Pages.

## Editing

- `projects.json`: project text and image lists
- `assets/`: artwork images
- `style.css`: responsive styling
- `app.js`: language switching, filters and galleries

All artwork remains the property of its respective creator.
